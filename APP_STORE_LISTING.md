## App Review Information

- **Notes:**
```
WClock is a bedside clock. It deliberately keeps the screen awake while the app is open (it turns off auto-lock) so it can be used all night, and it lowers the screen brightness at night when the "Dim screen at night" setting is on (default). Brightness is restored when the app is closed or the setting is turned off.

Location (while using the app, approximate) is used only to fetch local weather from Apple WeatherKit and to compute sunrise/sunset for the automatic day/night switch. No account or login is needed.

Settings are behind the "…" button in the top-right corner.
```
